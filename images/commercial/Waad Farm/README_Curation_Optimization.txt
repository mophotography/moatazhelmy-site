OPTIMIZATION
------------
- Curated web images resized proportionally to a maximum of 1600 px on the longest edge; no upscaling.
- JPEG quality 85, optimized and progressive encoding. Where a re-encode would increase file size, compression was adjusted; an already smaller source was retained unchanged.
- Original aspect ratios preserved. No cropping, retouching, colour grading, brightening or AI reconstruction.
- Embedded ICC colour profiles retained where present. No profile assigned where absent.
- EXIF metadata removed from re-encoded web copies; all source originals remain unchanged in the separate originals folder.
